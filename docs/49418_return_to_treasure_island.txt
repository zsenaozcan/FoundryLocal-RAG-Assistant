Title: Return to Treasure Island (1988)
Genres: Adventure, Animation, Comedy
Director: David Cherkasskiy
Main Cast: Armen Dzhigarkhanyan, Viktor Andrienko, Valeriy Bessarab, Boris Voznyuk, Georgiy Kishko
Keywords: treasure, island, pirate, adaptation, live action and animation, treasure island

Overview: A USSR-made violent farcical yet quite faithful adaptation of the famous Robert Louis Stevenson's book that combines animated sequences with live action parts.
