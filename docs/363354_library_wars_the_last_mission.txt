Title: Library Wars: The Last Mission (2015)
Genres: Romance, Action, Comedy
Director: Shinsuke Sato
Main Cast: Junichi Okada, Nana Eikura, Chiaki Kuriyama, Kei Tanaka, Sota Fukushi

Overview: Set 18 months after movie "Library Wars." After the government's enactment of the Media Betterment Act, battles wage between the Betterment Squads and the Library Defense. The Library Defense resists censorship and advocates freedom of expression. The biggest battle awaits for the Library Defense.
