Title: Ill Met by Moonlight (1957)
Genres: War, Adventure, Action, Drama
Director: Emeric Pressburger
Main Cast: Dirk Bogarde, Marius Goring, David Oxley, Dimitri Andreas, Cyril Cusack
Keywords: general, kidnapping, crete, partisan, morse code
