Title: Code Name Coq Rouge (1989)
Genres: Unknown
Director: Per Berglund
Main Cast: Stellan Skarsgård, Lennart Hjulström, Krister Henriksson, Philip Zandén, Bengt Eklund
Keywords: suspense, espionage

Overview: Han heter Carl Hamilton. Han är specialutbildad av CIA. Säpo vill inte ha honom, men måste ta honom ändå när terrorister baserade i Sverige hotar att sätta sina mordiska planer i verket. När alla utvägar är prövade och stängda - då kallar man in Carl Hamilton.
