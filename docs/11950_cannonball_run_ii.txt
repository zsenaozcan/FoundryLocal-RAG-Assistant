Title: Cannonball Run II (1984)
Genres: Action, Comedy
Director: Hal Needham
Main Cast: Burt Reynolds, Dom DeLuise, Dean Martin, Sammy Davis, Jr., Shirley MacLaine
Keywords: car chase, race, amphibious vehicle, nun costume
