Title: The Apocalypse Code (2007)
Genres: Action, Adventure
Director: Vadim Shmelyov
Main Cast: Anastasiya Zavorotnyuk, Vincent Pérez, Vladimir Menshov, Oskar Kuchera, Aleksey Serebryakov

Overview: Terrorist Jaffad Ben Zayidi steals four nuclear bombs from a sunken American submarine and hides them in four major cities throughout the world. The charges can be activated by an 11-digit code. Zayidi dies and his accomplice, nicknamed "The Executioner," is about to blow up the bombs. The Executioner is chased by FSB, whose agent Marie has previously infiltrated Zayidi's team.
