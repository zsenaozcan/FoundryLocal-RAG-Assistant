Title: Peace Code (2014)
Genres: Crime, Action, Adventure
Director: Pedro Urrutia
Main Cast: David Maler, Paula Sánchez Ferry, Héctor Aníbal, Nashla Bogaert, José Guillermo Cortines

Overview: Pedro Ruiz is a Dominican real estate broker by day and a savvy but out-of-luck thief by night. Desperate to look for respect climbing the money ladder the easy way, he gets in the wrong mansion at the wrong time.
